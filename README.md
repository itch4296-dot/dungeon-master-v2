# Dungeon Code — Версия 1.0 «Мастер подземелья»

Добро пожаловать в предрелизную версию Dungeon Code! В этом обновлении мы значительно улучшили систему распределения лута, добавили аналитику предметов и внедрили боевое логирование.

## Новые возможности (Релиз v1.0):
* **Аналитический фильтр ценности**: Система теперь автоматически фильтрует и выводит список редких (`rare`) и легендарных (`legendary`) артефактов.
* **Топ-5 лучших предметов**: Реализован быстрый подсчет и вывод пяти самых мощных предметов экипировки.
* **Генератор добычи (Loot Generator)**: Оптимизирована выдача наград с помощью ленивого генератора (`yield`), что экономит память устройства при генерации бесконечного лута.
* **Боевое логирование (`@log_action`)**: Все атаки персонажей теперь автоматически регистрируются в консоли разработчика.
* **Профайлер производительности (`@timer`)**: Добавлен инструмент замера скорости выполнения боевых функций с точностью до микросекунд.

## Как запустить тесты новой версии:
1. Запустите скрипт проверки:
   ```bash
   python game_advanced.py
   ```
